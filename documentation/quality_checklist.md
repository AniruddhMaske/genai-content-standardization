# Content Quality Checklist

## Before processing

- [ ] Keep an unchanged copy of the source.
- [ ] Confirm the input is UTF-8 text and is appropriate to process in the
      selected tools.

## After automated cleanup

- [ ] Read the full standardized output against the source.
- [ ] Review all placeholder, duplicate-paragraph, and long-line findings.
- [ ] Confirm headings, lists, and paragraph breaks still communicate the
      intended structure.
- [ ] Confirm names, numbers, dates, quotations, links, and claims are
      unchanged and correct.

## After Copilot review (if used)

- [ ] Compare every proposed edit with the source and accept only supported
      changes.
- [ ] Verify factual claims with an authoritative source; neither the script
      nor Copilot establishes accuracy.
- [ ] Check that no content was omitted, added, or given a different meaning.
- [ ] Obtain content-owner approval and retain the approved final version.
